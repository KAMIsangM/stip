## 用户需求

改进最短学习路径算法，实现加权最短路径和节点重要度加权。

## 功能内容

1. **边权重设置**：为不同类型的边设置不同权重（prerequisite=1, contains=2, causal=2, related=3），权重越低代表关系越强。
2. **节点重要度加权**：节点 importance 越高（0~1），优先经过该节点。通过将节点代价融入边权重实现（拆点法）。
3. **算法升级**：从无权 BFS 改为带权 Dijkstra 算法（通过 NetworkX 的 `shortest_path(weight='weight')` 实现）。

## 视觉效果

无 UI 变更，仅后端算法改进。前端调用方式不变（API 输入输出不变）。

## 技术栈

- 后端：Python + FastAPI + NetworkX
- 算法：Dijkstra 最短路径（带权）
- 节点权重实现：拆点法（node-splitting）

## 实现方案

### 核心思路：拆点法（Node-Splitting）

NetworkX 的 `shortest_path(weight=...)` 只支持边权重，不支持节点权重。为了把节点重要度（importance）也纳入路径代价，采用**拆点法**：

1. 每个节点 `v` 拆成两个虚拟节点：`v_in` 和 `v_out`
2. 所有指向 `v` 的入边，改连到 `v_in`
3. 所有从 `v` 出发的出边，从 `v_out` 引出
4. 在 `v_in` 和 `v_out` 之间加一条"节点边"，权重 = 节点代价
5. 节点代价设计：`node_cost = (1 - importance) * IMPORTANCE_SCALE`

- importance=1.0（最重要）：节点代价=0，经过该节点无额外代价
- importance=0.0（最不重要）：节点代价=IMPORTANCE_SCALE，经过该节点代价高

6. 边权重：prerequisite=1, contains=2, causal=2, related=3

最终调用 `nx.shortest_path(G_weighted, source_out, target_in, weight='weight')` 计算路径，然后把拆点路径还原为原始节点序列（去重）。

```python
def shortest_path_weighted(
    nodes: list[dict[str, Any]],
    edges: list[dict[str, Any]],
    source: int,
    target: int,
    importance_scale: float = 5.0,  # 节点代价缩放因子
) -> list[int] | None:
    """加权最短路径（边权重 + 节点重要度）"""
    # 1. 构建拆点图
    G = nx.DiGraph()
    
    # 2. 添加拆点节点
    for n in nodes:
        nid = n["id"]
        imp = n.get("importance", 0.5)
        node_cost = (1.0 - imp) * importance_scale
        G.add_node(f"{nid}_in")
        G.add_node(f"{nid}_out")
        # 节点边：代价 = (1-importance)*scale
        G.add_edge(f"{nid}_in", f"{nid}_out", weight=node_cost)
    
    # 3. 添加拆点边
    for e in edges:
        src = e["source_node_id"]
        tgt = e["target_node_id"]
        rel = e.get("relation_type", "related")
        # 边权重
        weight_map = {
            "prerequisite": 1.0,
            "contains": 2.0,
            "causal": 2.0,
            "related": 3.0,
        }
        w = weight_map.get(rel, 3.0)
        G.add_edge(f"{src}_out", f"{tgt}_in", weight=w)
    
    # 4. 调用 Dijkstra
    try:
        raw_path = nx.shortest_path(G, 
                                   source=f"{source}_out",
                                   target=f"{target}_in", 
                                   weight="weight")
        # 5. 还原为原始节点序列（去重）
        result = []
        for node_name in raw_path:
            nid = int(node_name.split("_")[0])
            if not result or result[-1] != nid:
                result.append(nid)
        return result
    except (nx.NetworkXNoPath, nx.NodeNotFound):
        return None
```

### 注意事项

1. **拆点法复杂度**：需要遍历所有节点和边，时间复杂度 O((V+E) log V)，对于课程知识图谱（通常 V<1000）性能完全足够。
2. **IMPORTANCE_SCALE 选择**：建议设为 5.0，这样节点代价范围 [0, 5.0]，边权重范围 [1, 3]，节点代价和边权重在同一量级，不会被某一方主导。
3. **向后兼容**：`shortest_path()` 函数保持原签名兼容（新增参数有默认值），现有调用无需修改。
4. **前端无需修改**：API 输入输出格式不变，前端 `KnowledgeGraph.vue` 中的路径高亮逻辑无需改动。
